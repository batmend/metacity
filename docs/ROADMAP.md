# Замын зураг

## 0. Одоо (демо) ✅
- Tile үйлдвэр (өөрийн PMTiles бичигч, схем, ерөнхийлөлт, budget), planetiler OSM схем + тест
- Загвар: өдөр/шөнө × 2D/3D, монгол нэршил, өөрийн фонт
- PWA: 2D/3D, хайлт, барилга → үйлчилгээ, үйлчилгээний каталог, гомдол мэдээлэх (локал), өгөгдлийн хэмжүүр
- CI: typecheck, test, build, хэмжээний тайлан

## 1. Бодит өгөгдөл (2–3 долоо хоног)
- [ ] `build-osm.sh`-ийг Улаанбаатарын OSM дээр ажиллуулж, схемийн зөрүүг засах; хэмжээг хэмжих (z15 tile budget)
- [ ] Барилгын өндөр: OSM `height`/`building:levels` хангалтгүй бол кадастрын давхрын тооноос join
- [ ] Байгууллага ↔ барилга ↔ үйлчилгээ бүртгэл (CSV → `services` атрибут)
- [ ] Дүүрэг/хорооны хил (бодит), хорооллын нэршил
- [ ] Хайлт: 50k+ бичлэгт индекс → серверт (Typesense/Meilisearch) эсвэл tile-д суурилсан локал индекс

## 2. Платформын суурь (1–2 сар)
- [ ] `apps/api` (Hono/Node эсвэл Go): үйлчилгээний каталог, гомдол/санал (11-11), байгууллага, хайлт
- [ ] Нэвтрэлт: ДАН / e-Mongolia OAuth; иргэн өөрийн хаяг, өргөдлийн төлөв
- [ ] Гомдлын төлөв (шинэ → хүлээн авсан → шийдсэн), дүүргийн ажилтны самбар
- [ ] Үйлчилгээний deep link: Meta City дотроос e-Mongolia-гийн тодорхой үйлчилгээ рүү
- [ ] Автобус: бодит цагийн байршил → tile биш, GeoJSON stream давхарга

## 3. 3D ба digital twin гүнзгийрүүлэлт
- [ ] Газрын өндөр (DEM → terrain-RGB tile, PMTiles): Богд уул, Зайсан харагдана
- [ ] Сонгосон дурсгалт барилга: 3D Tiles / glTF давхарга (зөвхөн ойртоход татагдана)
- [ ] Барилгын хэлбэр: `min_height` (давхарласан хэсэг), дээврийн төрөл
- [ ] Инженерийн шугам (ус, дулаан, цахилгаан) давхаргууд: зөвшөөрөлтэй хэрэглэгчид
- [ ] Бодит цагийн мэдрэгч (агаарын чанар, замын ачаалал) → "амьд" давхарга
- [ ] MLT (MapLibre Tiles) формат руу шилжих: tile 2–3× жижигрэнэ

## 4. Апп (дэлгүүр)
- [ ] Capacitor багцлал (Android/iOS): ижил web bundle, native shell 3–5 MB; OTA шинэчлэл SW-ээр
- [ ] Offline: хэрэглэгчийн сонгосон дүүргийн tile-уудыг урьдчилан татах (go-pmtiles `extract` → жижиг архив)
- [ ] Push мэдэгдэл: гомдлын төлөв, ус/дулаан тасралт

## 5. Хот бүхэлдээ, дараа нь бусад хот
- Схем, pipeline, загвар бүгд хотоос үл хамаарна. Дархан, Эрдэнэт = шинэ bbox + байгууллагын бүртгэл.
